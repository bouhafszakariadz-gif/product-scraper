# خدمة جلب معلومات المنتج

هاد السكريبت يستقبل رابط منتج، ويرجعلك: العنوان، الصورة، الوصف، والسعر (إذا لقاه).

## كيفاش تشغلها عندك بصفة دائمة (مجاناً) — خطوة بخطوة

### 1. حط الكود فـ GitHub
- سولي حساب فـ github.com (إذا ماعندكش)
- دير repository جديد، وارفع فيه هاد الملفات الثلاثة (`server.js`, `package.json`, `README.md`)
- كاين شرح فيديو بالعربي على يوتيوب "رفع مشروع لـ GitHub" إذا احتجت

### 2. استضف السكريبت مجاناً على Render.com
- سولي حساب فـ render.com (تقدر تدخل بحساب GitHub تاعك مباشرة)
- اضغط "New +" ثم "Web Service"
- اختار الـ repository اللي رفعتي
- فـ Build Command حط: `npm install`
- فـ Start Command حط: `npm start`
- اختار الخطة المجانية (Free) واضغط Create Web Service

### 3. بعد دقائق، Render يعطيك رابط
راح يبان شي حاجة بحال:
`https://product-scraper-xxxx.onrender.com`

هاد الرابط هو "الخادم" (API) تاعك اللي راح يخدم من التطبيق.

### 4. كيفاش تستعملها من التطبيق (الموقع اللي بنيناه)
من التطبيق، فباللصق رابط منتج، بدل ما تكتب المعلومات يدوياً، التطبيق يقدر يبعت طلب لـ:
```
POST https://product-scraper-xxxx.onrender.com/api/fetch-product
Body: { "url": "https://رابط-المنتج" }
```
وترجعلو المعلومات جاهزة (عنوان، صورة، سعر) باش يعمر بيها الفورم أوتوماتيكياً.

## ملاحظة مهمة
- الخطة المجانية فـ Render "تنعس" إذا محدش استعملها لمدة، وتحتاج شوية وقت (~30 ثانية) باش تفيق فأول طلب - عادي بالنسبة لمشروع بداية
- بعض المواقع (خصوصاً Amazon) عندها حماية ضد الطلبات الآلية، يمكن ما يخدمش مليح مع كل المواقع من أول مرة - إذا صرا هذا، نقدرو نزيدو تحسينات
- استعمال روابط affiliate رسمية (Amazon Associates، إلخ) هو الطريقة الأضمن والأقانونية باش تربح عمولة
